# SpecDD project specific overrides

## Spec Kit Integration
- SpecDD remains the Single Source of Truth for system architecture, global governance, and security (Envelope Encryption).
- GitHub Spec Kit is used for feature-level specs (e.g. adding a new Collector, new endpoints, or transformation rules).
- Spec Kit features MUST NOT violate SpecDD `Must not` or `Forbids` constraints.
- For more details on the integration and mapping, refer to `docs/SpecDD_SpecKit_Integration_EN.md` (or the `_DE` version).
